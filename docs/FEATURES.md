# 功能说明

- 登录与注册：登录成功后保存 Bearer Token 到应用会话。
- 资料：当前用户可编辑昵称、生日、性别和兴趣。
- 角色：读取当前认证用户的启用角色，支持在应用顶部切换；没有角色时阻止聊天、记忆和关系接口调用。
- 聊天：首次加载认证用户与所选角色的历史消息，支持游标读取更早消息；新回复以 SSE 分片实时显示，流中断时保留已收到内容并提示用户。
- 羁绊：展示亲密度、信任度、情绪与等级。
- 记忆：展示当前认证用户的长期对话摘要和关系事件，支持编辑内容、调整重要度和删除。
- 通知：加载通知、仅看未读、标记已读，并可控制是否接收主动陪伴提醒。

用户 ID 从登录 JWT 解析，后端仍以 JWT 身份为准。
